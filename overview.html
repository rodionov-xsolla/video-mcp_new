Video Production Pipeline

AI-конвейер коротких вертикальных роликов (1080×1920) для game-каналов. Сценарий, голос, изображение, видео, монтаж — всё через сабагенты Claude поверх fal.ai, ElevenLabs, FFmpeg и Supabase.

Стек: Claude Code (Opus/Sonnet/Haiku) · fal.ai · ElevenLabs · Supabase · FFmpeg Корень: video-agent/ Формат: 1080×1920, 25–60s Стоимость ролика: $1.5–$6

Поток файла storyboard.json

Один JSON растёт через все 4 фазы: каждый агент дописывает свои поля, не удаляя чужие.

Scenarist     →  scenes[].narrative_text, action_description, facial_expression,
                 character_state, visual_identity, voices, duration_sec, clip_type

Sound         +  scenes[].tts_url       (Supabase public URL .mp3)
              +  scenes[].tts_dur       (ffprobe seconds)
              +  bg_music_url

Storyboarder  +  scenes[].image_prompt  (для NB2)
              +  scenes[].scene_image_url   (Supabase public URL .png)

Animator      +  scenes[].motion_prompt (для Kling)
              +  scenes[].clip_url      (локальный путь .mp4)
              +  cost_log[]

Editor        →  читает всё, пишет final.mp4 на диск + загружает в Supabase

Sub-agents — пять ролей

Manager parent

Оркестратор. НЕ пишет storyboard, НЕ зовёт fal.ai, НЕ запускает ffmpeg. Только Agent-вызовы + git + детект формата + cost report.

Что делает

  • git pull origin main в самом начале
  • Детект формата из user request → читает rules/formats/{format}.md
  • Делегирует 5 фаз через Agent tool
  • Программатическая валидация после каждой фазы (filesize, ffprobe — без визуальной читки PNG/MP4)
  • Обновляет story bible (для serial-drama / reddit-story)
  • Финальный cost report + git push

rules/roles/manager.md

Scenarist sonnet

Пишет storyboard.json (narrative side). Никаких изображений, видео, аудио.

Что делает

  • Сцены/биты, action_description, dialogue
  • visual_identity, facial_expression, character_state
  • Согласует длительности с budget'ом формата
  • Для серий — читает story bible, дописывает её

rules/roles/scenarist.md · prompts/scenarist.txt

Sound haiku

TTS для каждой диалоговой реплики. Загрузка MP3 в Supabase, URL'ы обратно в storyboard.json. Выбор bg-music.

Что делает

  • Для каждого clip_type: dialogue — POST в MiniMax Speech 2.8 HD (все игры) или Chatterbox (Genshin serial-drama)
  • Voice mapping из game config (Kirk, Worf, Narrator, и т.д.)
  • Загрузка MP3 в Supabase Storage, public URL
  • Подбор bg-music из music/{Dark|Fun|Neutral}/ по format mood
  • Для длинных монологов (>30s в одной сцене) — резка по предложениям (NB: не для Avatar — там hard cap 25s)

rules/roles/sound.md · prompts/sound.txt

Storyboarder sonnet

Переводит action_description в image_prompt, генерит PNG через Nano Banana 2, грузит в Supabase. Chain-ref для consistency.

Что делает

  • Решает камеру, угол, оптику, гэйз персонажей
  • Chain-ref: scene-N = [character-sheet, scene-(N-1)] для continuity
  • NB2 prompt-engineering (без негаций, photographic vocabulary)
  • Для Avatar-сцен — zero-text rule (никакого текста в кадре, иначе Kling превратит в иероглифы)
  • Программатическая валидация PNG: filesize, dimensions, ffprobe

rules/roles/storyboarder.md · prompts/storyboarder.txt

Animator sonnet

Kling I2V (action) или Kling Avatar v2 (dialogue/lipsync). Самая дорогая фаза — $0.28–$1.40 за вызов.

Что делает

  • Пишет motion_prompt сам, из action_description + facial_expression
  • I2V: v3 Standard ($0.084/s) — primary; v2.6 Pro — fallback
  • Avatar: Kling Avatar v2 Standard ($0.056/s), hard cap 25s TTS
  • Multi-prompt для длинных action-сцен (до 15s, 6 shots)
  • Программатическая валидация MP4: filesize, ffprobe duration, video/audio streams

rules/roles/animator.md · prompts/animator.txt

Editor sonnet

FFmpeg-сборка final.mp4. Нормализация, concat, субтитры, музыка, CTA, загрузка в Supabase. Никаких AI-API.

Что делает

  • Trim каждого клипа (Avatar tail = TTS_dur + 0.3s)
  • concat через -f concat, нормализация SAR/FPS
  • Субтитры: add_subtitles.py (faster-whisper → ASS chunks по 3 слова)
  • Audio mix: voice 100%, bg-music ~20%, gameplay 25% (где есть)
  • Speedup (для gameplay-ai-avatar — 1.3×)
  • Upload final.mp4 в Supabase

rules/roles/editor.md · prompts/editor.txt

Publisher main session

Два флоу: (1) YouTube — приватная загрузка с отложенной датой после генерации; (2) TikTok/Instagram — post-now через mobile-mcp (Android по USB).

YouTube (основной флоу)

  • Запускается после генерации — спрашивает сколько роликов загрузить
  • Смотрит последнюю запланированную дату из video_agent_runs.yt_published и ставит следующий ролик на day+1 в 20:59 UTC (23:59 МСК)
  • Загружает как private + publishAt через youtube-upload.sh
  • Записывает дату в yt_published через log-publish.sh --platform yt

TikTok / Instagram (post-now)

  • Триггер — явная команда: «опубликовать в тик-ток starfleet»
  • fetch-for-publish.sh скачивает ролик из Supabase, кладёт через adb
  • mobile-mcp открывает приложение, выбирает аккаунт и видео

Внешние сервисы

fal.ai

Прокси к моделям. Четыре семейства: NB2 (картинки), Kling (видео), ElevenLabs (голос), Chatterbox (voice-clone TTS).

Эндпоинты в работе

  • fal-ai/nano-banana-2 — text-to-image
  • fal-ai/nano-banana-2/edit — chain-ref edit
  • fal-ai/kling-video/v3/standard/image-to-video — I2V primary
  • fal-ai/kling-video/v2.6/pro/image-to-video — I2V fallback
  • fal-ai/kling-video/ai-avatar/v2/standard — Avatar lipsync
  • fal-ai/minimax/speech-2.8-hd — TTS (все игры кроме Genshin)
  • fal-ai/chatterbox/text-to-speech — voice-clone TTS (Genshin serial-drama)

Async очередь. fal.ai temp-URLs живут часами — поэтому всё перезаливаем в Supabase до Kling-вызова.

Supabase

Постоянное хранилище всех ассетов + БД с метаданными.

Storage

  • assets/{game}/refs/ — character sheets, bg-refs (шарятся между эпизодами)
  • assets/{game}/scenes/{date}/{format}/ — scene PNGs (per-эпизод, чтоб не затирались)
  • assets/{game}/tts/ — MP3
  • assets/{game}/final/ — готовые final.mp4

DB

  • game_assets — реестр ассетов (URL, tags, prompt_block)
  • video_tasks — очередь для worker'а (queue mode)

ElevenLabs / Chatterbox

Два TTS-бэкенда через fal.ai. Выбор по game_tag: Chatterbox для Genshin serial-drama (voice-clone из reference MP3), ElevenLabs eleven-v3 для всех остальных.

Голоса

  • Voice mapping в sound.md + per-game в game config
  • Per-character settings ElevenLabs (Kirk: stable, Spock: flat, Worf: harsh)
  • Chatterbox: JSON-тело пишется через Python (не bash heredoc — апострофы убивают аудио)

FFmpeg

Локально, версия с libass (для ASS-субтитров). Никаких облаков.

Используется

  • Editor: concat, trim, atempo, amix, drawbox, subtitles burn-in
  • Animator: ffprobe (validation), bridge-frame extraction (multi-call chain)
  • Sound: ffprobe duration
  • Бинарь: /usr/local/bin/ffmpeg-full/ffmpeg (libass-enabled)

Принципы

  • Manager не делает работу sub-agent'ов. Если делает — всё едет на parent-Opus, стоимость x3.
  • Не читай PNG/MP4 визуально. Валидация — только программатическая (filesize + ffprobe). Качество — на уровне промпта, не на инспекции глазами.
  • Никогда не из памяти — всегда читай rule-файлы. Правила меняются.
  • Перед дорогим вызовом — Supabase upload. fal.ai temp-URLs протухают, Kling за $1.40 не успеет скачать.
  • storyboard.json — единственный канал между фазами. Sub-agent'ы не видят чужой контекст.
  • Debug mode — остановка после каждой фазы для confirm.
