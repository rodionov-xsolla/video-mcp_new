# Roblox

## Метаданные

- **Жанр:** Sandbox / Social Platform
- **Платформа:** PC, Mobile, Console
- **Аудитория:** Gen Z / Gen Alpha, глобальная, 8-18 лет
- **Стиль арта:** Blocky 3D, Pixar-like, яркие пластиковые текстуры

---

## Visual Style Guide

### Цветовая палитра
- Основные: bright yellow (#FFD700), electric blue (#00BFFF), vivid green (#32CD32)
- Акценты: neon pink (#FF69B4), hot red (#FF3333), deep purple (#7B2FBE)
- Фон: soft gradient pastels, пастельные тона для интерьеров

### Освещение
- Мягкое ambient, Pixar-style global illumination
- Цветные акцентные источники (neon signs, glowing items)
- Без резких теней — всё мягкое и "пластиковое"

### Композиция
- Персонаж крупно в центре, 9:16 vertical
- Окружение — стилизованное, blocky, toy-like
- Глубина резкости: персонаж в фокусе, фон слегка размыт

### Prompt prefix
```
Roblox-inspired Pixar-style 3D animation, blocky stylized characters, smooth plastic-like skin texture, expressive cartoon faces, vibrant saturated colors, soft ambient lighting, cinematic depth of field, toy-like proportions
```

## Serial Drama Config

### Стиль для serial-drama формата
```
Roblox-inspired Pixar-style 3D animation, blocky stylized characters, smooth plastic-like skin texture, expressive exaggerated cartoon faces, vibrant saturated colors, soft ambient lighting, cinematic depth of field, toy-like proportions, dramatic emotional expressions
```

### Типичные локации
- **Server Lobby:** открытое пространство с неоновыми вывесками, спаун-поинт, floating UI elements
- **Rich Player's Mansion:** гигантский дом из золотых блоков, фонтан, luxury cars на подъезде
- **Dark Alley:** узкий проход между блочными зданиями, неоновые вывески, тени, мусорные блоки
- **Adopt Me Playground:** яркая детская площадка, питомцы, радуга, пастельные цвета
- **Battle Arena:** каменная арена с трибунами, факелы, драматичное освещение
- **School Hallway:** блочный школьный коридор, локеры, флуоресцентное освещение

### Музыка
- **Mood:** dramatic, emotional, comedic
- **BPM:** 100-130
- **Рекомендуемые жанры:** lo-fi beats (грустные моменты), trap beats (драматичные), comedy stings (повороты сюжета)
