## Visual Style Guide

### Цветовая палитра
- Основные: forest green (#2d7a3a), sky blue (#4da6e0), warm gold (#e8b840)
- Акценты: crimson red (#c43030), royal purple (#7a3db8), dark slate (#3a3a4a)

### Освещение
- Bright fantasy lighting, warm tones
- Magical glow effects (fire, spells, enchanted items)
- Soft ambient light for outdoor medieval scenes

### Композиция
- Персонажи крупным планом — chibi/cartoon стиль с bold outlines
- Яркие насыщенные цвета, flat shading для cartoon-версий
- Фон: средневековые деревни, тёмные леса, замки, подземелья

### Prompt prefix
```
Kakele Online MMORPG style, colorful cartoon fantasy, vibrant chibi character art, bold black outlines, bright saturated colors, medieval fantasy world
```
